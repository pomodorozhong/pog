# Progress: 2026-10-13

Milestone 3 (graces from game data) of [the plan](../plan.md) is done. This note keeps what the plan leaves out.

## Param layouts (from soulsmods/Paramdex `ER/Defs`)

| Param                   | Row size | Fields used (offset)                                                                                                        |
| ----------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------- |
| BonfireWarpParam        | 236      | `eventflagId` u32 @4, display mask u8 @30, `areaNo`/`gridXNo`/`gridZNo` u8 @32–34, `posX/Y/Z` f32 @36–44, `textId1` s32 @48 |
| WorldMapLegacyConvParam | 48       | source `area, gridX, gridZ` u8 @4–6 + `pos` 3×f32 @8; destination the same at @20 and @24                                   |

- **Display mask:** bit 0 = shown on the surface map, bit 1 = shown on the underground map. Every DLC grace has mask 0.
- **`textId1`:** a `PlaceName` text ID, so grace names come from the same tables as place names.

## Legacy conversion

- **Rows:** 196. A row says "this point in map A is that point in map B"; the difference is a pure translation, no rotation or scale.
- **Both ways:** some maps only appear as a destination (Elden Beast's arena, area 19, is reached through the row `11_05 → 19`), so rows are followed in both directions.
- **Chains:** Deeproot Depths (12_03) goes through the Leyndell sewers (35) and Leyndell (11) to the overworld. The search prefers a direct link to area 60/61, then the conversion point nearest the grace.
- **Unresolved:** 3 rows: the unnamed row 0 and two unnamed rows in area 12_06.

## Finding the transform

- **What didn't work:** scoring candidate transforms by how many graces land on "land" (red − blue on the map image). The optimum was broad and noisy, and a scale bug in the first script made every candidate look perfect.
- **What worked:** crops of the map around graces at drawn landmarks. With the old guess (7040, 16640), Church of Elleh, Church of Dragon Communion and Third Church of Marika were all about 110–130 px south of their drawings. Moving to 16512 put them on the drawings within about 20 px.
  - **Round numbers:** 7040 = 27.5 × 256 and 16512 = 64.5 × 256, half-cell values, which suggests these are the game's own constants.
- **DLC:** the land score for the DLC map peaked at scale 1.0 with an offset within 50 px of the overworld's. With the exact overworld transform, Church of the Bud, Cathedral of Manus Metyr, Fort of Reprimand, Scadutree Base, Belurat and Shadow Keep all sit on their drawings.
- **Underground:** the same transform puts all 30 underground graces (Siofra, Nokron, Ainsel, Lake of Rot, Deeproot) on the drawn caverns.
- **Legacy dungeons:** Stormveil, Raya Lucaria, Leyndell, the Elden Beast arena (projected onto the Erdtree) and Shadow Keep line up too.
- **Stone Coffin Fissure:** its four graces, including the open-world "The Fissure", land south of the Cerulean Coast over the sea. The open-world grace is there too, so this matches the game's own coordinates.

## Counts

- **Import:** adds 279 overworld graces (5 ashen-capital twins share a name and spot with the normal Leyndell graces and are skipped) and 105 DLC graces.

## App details not in the plan

- **Refs:** imported grace nodes link to `grace/<BonfireWarpParam row ID>`. Grace nodes now search graces instead of place names, which settles the duplicate place ID problem from 2026-10-12. Existing `place/…` links still display.
- **Import edits:** one `batch` map action, so a whole import is one undo step.
- **Hand-placed graces:** an unlinked grace node (or one linked to a place name) within 48 px of a game grace is linked to it and keeps its position. Unlinked grace nodes show the 5 nearest graces as suggestions.
- **Player data:** the player's own `map.json` was not changed. It holds one hand-placed grace 160 px from the nearest game grace (Waypoint Ruins Cellar), so the import will add a node next to it rather than link it.
- **Testing:** browser test against a scratch copy of the player data; unit tests are now 10 (3 new for the import).

## Loose ends

- **`dlc-underground`:** no graces are assigned to it (see the plan's follow-up).
- **Legacy graces on the overworld:** dungeons with many graces (Leyndell 16, Stormveil 9) stack them on the overworld map. Readable from zoom 4; the plan already keeps legacy dungeons as single entrance nodes for routing.
